# Android Lock Screen Pattern Generator

## Overview
This is a **Python-based Android Lock Screen Pattern Simulator** built using Tkinter. </br>
It generates **random valid patterns** following Android's lock screen rules and allows users to set custom patterns.

## Features
- 🔢 **Random Pattern Generation** ensuring valid movements
- 🎨 **Dynamic UI with Start (Green), End (Red), and Path (Cyan)**
- 🔘 **Unused Circles are Light Gray**

## Installation
1. **Clone the repository:**
   ```sh
   git clone https://github.com/mouli-dutta/LockScreenPatternGenerator.git
   cd LockScreenPatternGenerator
   ```
   
2. **Install dependencies:**
   ```sh
   pip install tk
   ```
   
3. **Run the Jupyter Notebook:**
   ```sh
   jupyter notebook LockScreenPatternGenerator.ipynb
   ```

## Usage

### Running in Jupyter Notebook
- Open lock_screen_pattern.ipynb in Jupyter Notebook.
- Click Kernel > Restart & Run All to execute all cells automatically.

### Random Pattern Generation
- Click **"Generate Pattern"** to display a new valid lock pattern.
- Adjust the **length slider** to set the pattern length (4-9).

### Pattern Visualization
- **Start Node:** Green
- **End Node:** Red
- **Path:** Blue
- **Unused Nodes:** Light Gray
